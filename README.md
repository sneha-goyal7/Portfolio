## ✨ Features

- **Loading screen:** "Brewing some cool things" with jumbled letters that settle after 3 seconds
- **Hero:** huge animated name over a purple-pink gradient, a wavy tagline, and a custom circle cursor
- **GitHub tablet:** a tilted tablet showing my GitHub profile, click to open it
- **About:** terminal-style intro (`whoami`, `skills.txt`, `achievements.txt`) and a live LeetCode stats card
- **Journey:** timeline of education and certifications
- **Featured projects:** a sideways-scrolling row of project cards (drag, scroll or use the arrows), each card opens the project
- **Contact:** email, location, GitHub and LinkedIn
- Responsive on mobile and desktop, and respects reduced-motion settings

## 💻 Run Locally

Want to see it first? Visit the [live demo](https://sneha-goyal-portfolio.netlify.app/).

No installation needed.

```bash
git clone https://github.com/sneha-goyal7/<your-repo-name>.git
cd <your-repo-name>
```

Then open `index.html` in your browser. For a local server, you can also run:

```bash
npx serve
```

## 🛠️ Customize

- **LeetCode stats:** edit the `CONFIG` block at the top of `script.js`. Live stats load automatically; the numbers in `CONFIG` show only if the fetch fails.
- **Loader time:** change `loaderMs` in `CONFIG` (in milliseconds).
- **Resume:** replace `resume.pdf` with your new file, keeping the same name.
- **GitHub image:** replace `github.png` with a new screenshot, keeping the same name.
- **Projects and text:** edit the cards and sections in `index.html`.
- **Colors:** change the gradient in the `.blob` rule in `style.css`.
